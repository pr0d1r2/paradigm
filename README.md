# paradigm

How a fleet of repositories is built by coding agents without anyone
watching them: agents write the code, guardrails decide what lands.

Status: draft. The design is specified in [`SPEC.md`](SPEC.md) and the
node specs it federates; [`SPEC-PROMPT.md`](SPEC-PROMPT.md) is the prompt it
grew from. The pages fill in during the build waves.

## Language pages

The main pages use Rust as the worked example. Other languages:

- [Ruby](docs/RUBY.md)
- [Shell](docs/SHELL.md)
- [Nix](docs/NIX.md)
