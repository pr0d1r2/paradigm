# Contributing to paradigm

Thanks for looking. paradigm is a method, written down, and checked by the
same gate it describes; this page is the short version of how to change it.

## Getting set up

Enter the dev shell with `direnv allow` or `nix develop`. Every tool the
gate runs comes from it, pinned by `flake.lock`, and the shell points git
at the tracked hooks in `.githooks/`.

## The gate

Every commit runs hk's pre-commit and commit-msg hooks; every push runs
the full gate, which you can also run by hand with `hk check --all`. The
hooks refuse when hk is missing. Never use `--no-verify`: when the gate
refuses, it is working, and its message says what to do.

## Commits

- One change per commit.
- Subject `type(scope): claim`; the body says why.
- The subject or body cites the spec ids it serves: a task `T<n>`, an
  invariant `V<n>` or a bug `B<n>`.
- The last paragraph of the message carries a `Paradigm-Stage:` trailer
  naming the stage the commit belongs to, with no blank line before
  `Co-Authored-By:` or any other trailer. The commit-msg hook refuses an
  unknown stage.
- A commit that is red on purpose says `RED` in its subject and still
  compiles.
- A new gate step comes with proof, in its commit body, that it rejects a
  planted violation.

## Pages and specs

Pages under `docs/` are prose for humans: claim first, evidence second,
how-to last, readable on a phone. Every number on a page carries the date
it was true and a row in [the numbers ledger](NUMBERS.md).

The rules are a federated spec: [`SPEC.md`](../SPEC.md) at the root and one
`SPEC.md` per node. Change the spec with the page or code it describes.
`§N` tables are generated by `sherd sync`; never edit them by hand.

Private repositories are never named in committed text. A repository you
name or link must be public and listed in
[`dev/public-repos.toml`](../dev/public-repos.toml); adding a row is its
own commit.

## Reporting problems

Bugs, disagreements with a rule and ideas go in GitHub issues. Security
problems go through [`SECURITY.md`](SECURITY.md), not a public issue.
